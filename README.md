# aegis_intelligence_platform
Aegis is a client-side ML transaction anomaly platform. It transforms raw ingestion streams via an interactive ETL sandbox, runs deep learning Autoencoder inference in-browser (TensorFlow.js), and builds compliance-ready Explainable AI (XAI) diagnostics—providing high-performance fraud detection with zero server costs.
